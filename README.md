# 印刷版・インク 倉庫パレット管理システム (Plate & Ink Warehouse Manager)

印刷現場向けに設計された、2D直列グリッドパレット配置図と受注番号検索・作業者名記録を備えた倉庫管理Webアプリケーションです。

---

## 🌟 主な機能

1. **2D直列パレットマップ配置図**
   - 中央に通路なしの縦直列グリッド配置。
     - **上段：エリアA**: 縦11行 × 横2列（計22マス: `A-01-1` 〜 `A-11-2`）
     - **下段：エリアB**: 縦12行 × 横2列（計24マス: `B-01-1` 〜 `B-12-2`）
   - **空きマス**: 点線枠、「空き」バッジ
   - **保管中マス**: 保管中の受注番号（枝番付き）、版数、および各色の丸チップ（C, M, Y, K, 特色等）を表示
   - **検索ハイライト**: 該当パレットが黄色枠で点滅（パルスアニメーション）

2. **1パレットへの複数版・複数受注の合積み保管**
   - 1つのパレット枠内に異なる受注や複数の版を同居保管可能。
   - パレット内に複数の受注がある場合、「2受注」「計5版」のように集約バッジを表示。

3. **受注番号 検索・状態一覧画面（部分一致・複数検出・大型ボタン）**
   - 右上の検索窓に番号を入力してEnterまたは検索ボタンを押すと、専用の「受注ステータス一覧画面」へ遷移。
   - 途中番号でも部分一致で複数受注を一括検出（例: `10` で `#1042`, `#1088`, `#1099` 等がヒット）。
   - 各版がどのパレットにあるか、誰が作業中かを一目で把握。
   - 現場のタブレットでも押しやすい**大型アクションボタン**（`🚀 出庫する` / `📦 返却・入庫する` / `📍 マップで位置を確認`）を配置。

4. **作業者名の必須記録 ＆ 入出庫アクション**
   - 出庫（作業開始）、返却入庫、新規登録のすべての操作で作業者名を必須記録。
   - プリセット作業者ボタン（佐藤、鈴木、高橋、田中、渡辺、伊藤）＋直接入力に対応。

5. **現在使用中（持ち出し中）の版一覧サイドパネル**
   - 現場の印刷機にセットされて作業中の版を受注番号ごとに常時可視化。
   - ワンクリックで返却先パレット（空き枠または既存パレット合積み）を選んで返却可能。

6. **履歴ログ管理 ＆ CSVエクスポート**
   - すべての入出庫操作を日時・受注番号・パレット・版・作業者名付きで記録。
   - ワンクリックでCSVダウンロード可能（Shift-JIS/UTF-8 BOM対応）。
   - LocalStorageによるデータ自動永続化。

## 🚀 使い方・起動方法

本システムは外部ビルドツール不要のシングルページWebアプリケーション（React 18 + Tailwind CSS + Lucide Icons）として実装されています。

### 方法1: ブラウザで直接開く
`index.html` をダブルクリックしてブラウザで開くだけで即座に動作します。

### 方法2: ローカルWebサーバーで起動
```bash
# Pythonを使用する場合
python -m http.server 3456

# ブラウザでアクセス
http://localhost:3456/index.html
```
